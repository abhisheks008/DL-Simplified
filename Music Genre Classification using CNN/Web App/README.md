## Music Genre Classification — Web App

### Goal 🎯
A Streamlit-based web application that classifies the genre of an uploaded audio clip using a trained CNN model.

### Model(s) used for the Web App 🧮
CNN (Convolutional Neural Network) trained on mel-spectrogram representations of the GTZAN dataset.

### How to Run

```bash
pip install -r ../requirements.txt
streamlit run web_app.py
```

Upload a `.wav` file and the app will display the predicted genre along with a confidence chart.
