# Dataset

## Description

This project uses a patient health indicators dataset, used to train an Artificial Neural Network (ANN) for heart disease prediction. Developed for a Kaggle "playground series" competition.

---

## Features Used

- Age
- Sex
- Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Maximum Heart Rate
- Exercise-Induced Angina
- ST Depression
- Chest Pain Type
- EKG Results
- Slope of ST
- Number of Vessels (Fluoroscopy)
- Thallium Test Results

---

## Dataset Information

- Structured patient health records
- Target column: Heart Disease (Presence/Absence, mapped to 1/0)
- Suitable for binary classification

---

## Submission Format

id,Heart Disease

## Applications

- Heart Disease Risk Prediction
- Healthcare Analytics
- Patient Risk Stratification
