# Dataset

## Description

This project uses the **GoEmotions** dataset, a large collection of Reddit comments labeled with fine-grained emotion categories, used to train an LSTM model for multi-label emotion classification.

---

## Dataset Information

- Text comments as input
- 28 emotion categories plus a neutral label (29 target columns)
- Multi-label format (a comment can express multiple emotions)
- Suitable for multi-label text classification

---

## Dataset Source

Publicly available on Kaggle: GoEmotions (Google Emotions Dataset)

---

## Applications

- Emotion Detection
- Text Sentiment Analysis
- Social Media Monitoring
