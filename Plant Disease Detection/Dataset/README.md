# Plant Disease Detection Dataset

The dataset used in this project is a subset of the famous **PlantVillage Dataset**, specifically focused on Tomato and Potato leaves.

## Dataset Structure
The dataset contains images of healthy and diseased leaves categorized into:
- Potato Healthy
- Potato Early Blight
- Potato Late Blight
- Tomato Healthy
- Tomato Bacterial Spot
- Tomato Yellow Leaf Curl Virus

## How to Access the Dataset
You can download the dataset from Kaggle:
- Link: [PlantVillage Dataset on Kaggle](https://www.kaggle.com/datasets/emware/plantvillage-dataset)
