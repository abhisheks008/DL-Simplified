# Muffin vs Chihuahua Dataset

## Dataset Source

The dataset used in this project is available on Kaggle:

https://www.kaggle.com/datasets/samuelcortinhas/muffin-vs-chihuahua-image-classification

## Description

This dataset contains images belonging to two classes:

- Muffin
- Chihuahua

The objective is to build deep learning models capable of correctly classifying whether an image contains a muffin or a chihuahua.

## Dataset Structure

- Training Images
- Testing Images

## Note

Due to dataset size limitations, the dataset is not uploaded to this repository. Please download it from the Kaggle link above.
