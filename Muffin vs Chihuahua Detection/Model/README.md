# Muffin vs Chihuahua Detection

## Objective

The objective of this project is to classify images as either Muffin or Chihuahua using Deep Learning models.

## Models Used

1. Custom CNN
2. MobileNetV2
3. ResNet50
4. EfficientNetB0

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Dataset

Dataset Source:
https://www.kaggle.com/datasets/samuelcortinhas/muffin-vs-chihuahua-image-classification
