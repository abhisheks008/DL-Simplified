# Dataset

## Description

This project uses a patient medical and demographic dataset, used to train an Artificial Neural Network (ANN) for diabetes prediction.

---

## Dataset Information

- Structured patient records
- Demographic features (e.g., gender, ethnicity, education level, income level, employment status)
- Lifestyle features (e.g., smoking status, alcohol consumption)
- Target column: diagnosed_diabetes (binary)
- Suitable for binary classification

---

## Applications

- Diabetes Risk Prediction
- Healthcare Analytics
- Patient Risk Stratification
