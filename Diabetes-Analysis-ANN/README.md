# Diabetes Prediction using Artificial Neural Network (ANN)

## Overview

This project focuses on predicting diabetes using an Artificial Neural Network (ANN). The objective is to classify whether a patient has diabetes based on medical and demographic features.

The workflow includes preprocessing, feature encoding, model development, training, evaluation, and prediction.
