# Dataset

## BSD300 (Berkeley Segmentation Dataset)
- **Source:** UC Berkeley Computer Vision Group
- **URL:** https://www2.eecs.berkeley.edu/Research/Projects/CS/vision/bsds/
- **Size:** 300 natural images (200 train / 100 test)
- **Image size:** 321×481 pixels
- **Format:** JPEG

## Download
The dataset is downloaded automatically when running the notebook.
