# Images

This folder contains visualizations generated by the YouTube Transcript Summarizer.

## Generated Images:
- `model_comparison.png` — Bar chart comparing all 3 models (compression ratio, summary length, processing time)
- `rouge_scores.png` — ROUGE-1, ROUGE-2, ROUGE-L evaluation scores
- `word_reduction.png` — Pie charts showing word count reduction per model

> **Note:** Run the summarizer's comparison mode to auto-generate these images:
> ```python
> from youtube_transcript_summarizer import TranscriptSummarizer, plot_model_comparison
> summarizer = TranscriptSummarizer()
> df = summarizer.compare_models(text)
> plot_model_comparison(df, save_path="Images/model_comparison.png")
> ```
