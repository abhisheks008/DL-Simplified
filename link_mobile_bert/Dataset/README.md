# Dataset

## Description

This project uses a merged URLs dataset containing raw URL strings and their associated category label, used to fine-tune a MobileBERT model for URL classification.

---

## Dataset Information

- Two key columns: `url` (text) and `label` (category)
- Four target classes
- A random sample of 10,000 rows is used for training/testing
- Suitable for multi-class text classification

---

## Applications

- URL Classification
- Phishing / Malicious Link Detection
- Web Security Analytics
