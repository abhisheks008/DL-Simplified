## Dataset — Kaggle Astronomy Image Classification

**Source:** https://www.kaggle.com/datasets/abhikalpsrivastava15/space-images-category  

**Total Images:** ~1,107 

**Classes:** Galaxies (237), Constellations, Nebulae, Planets, Stars, Cosmos (166) 

**Note:** Dataset is slightly imbalanced — handled via class weights during training.
