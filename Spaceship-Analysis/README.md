# Spaceship Titanic Prediction using Artificial Neural Network

## Overview

This project implements an Artificial Neural Network (ANN) to predict whether passengers aboard the Spaceship Titanic were transported to an alternate dimension, based on passenger and travel features. The model performs binary classification for a Kaggle competition.

The workflow includes preprocessing, feature engineering, model development, training, evaluation, and prediction.
