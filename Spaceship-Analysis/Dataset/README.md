# Dataset

## Description

This project uses the Spaceship Titanic dataset, containing passenger travel and demographic information, used to train an Artificial Neural Network (ANN) to predict whether a passenger was transported.

---

## Key Features

- PassengerId
- HomePlanet
- CryoSleep
- Cabin (split into deck, num, side)
- Destination
- Age
- VIP
- RoomService
- FoodCourt
- ShoppingMall
- Spa
- VRDeck

---

## Dataset Information

- Structured passenger records
- Mix of categorical and numerical features
- Target column: Transported (binary)
- Suitable for binary classification

---

## Applications

- Passenger Outcome Prediction
- Kaggle Competition Analysis
