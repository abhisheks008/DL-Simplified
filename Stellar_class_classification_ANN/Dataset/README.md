-# Dataset

## Description

This project uses a stellar objects dataset from the Kaggle Playground Series, used to train an Artificial Neural Network (ANN) to classify celestial objects into stellar classes.

---

## Dataset Information

- Numerical astronomical features
- Spectral information (spectral_type)
- Galaxy population data (galaxy_population)
- Target column: class (multi-class)
- Suitable for multi-class classification

---

## Dataset Source

Kaggle Playground Series - Season 6, Episode 6 (Stellar Classification)

---

## Applications

- Stellar Object Classification
- Astronomical Data Analysis
- Kaggle Competition Analysis
