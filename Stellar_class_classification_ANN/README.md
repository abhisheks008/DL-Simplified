# Stellar Classification using Artificial Neural Network

## Overview

This project implements an Artificial Neural Network (ANN) to classify stellar objects into categories based on astronomical and spectral features. The model performs multi-class classification and was developed for a Kaggle Playground Series competition.

The workflow includes preprocessing, feature encoding, model development, training, and prediction.
